# Project 2: Tableau Dashboard of Pittsburgh Crimes
**67-290 Storytelling with Data Visualization | CMU-Qatar | Fall 2026**

## Overview

In this project, you will use Tableau to design and develop a dashboard to tell story about Pittsburgh crime using Western Pennsylvania Regional Data Center (WPRDC) datasets of Police Incident Blotter and Pittsburgh Police Arrest, the same data you used in Lab 2. The data files are in the Lab 2 folder: [`Labs/lab2/data/`](../../Labs/lab2/data/) (`arrests.zip` and `blotter.zip`).

Open **`Project 2 Tableau_Pittsburgh_Crimes.pdf`** for detailed instruction.
